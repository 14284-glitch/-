# 功能盤點與最小修改決策

盤點日期：2026-07-26

## 現有架構

- 語言：Python 3.11。
- 前端與路由：Streamlit；`app.py` 使用側邊欄單選導覽，頁面由 `pages/` 模組渲染。
- 狀態：Streamlit widget/session state；目前選擇股票新增為共用 session state。
- 圖表：Plotly；色彩與線型統一由 `config/color_config.py` 管理。
- 資料來源：Yahoo Finance（台美股行情及公司行動）、FinMind（法人、融資券、基本面與估值）、FRED／ALFRED（總體）、公開RSS新聞。
- 儲存：CSV快取、SQLite後台歷史庫及BigQuery雲端同步。
- 排程：GitHub Actions每日07:00、14:00、21:00；Streamlit另有手動更新。
- 測試：pytest，涵蓋圖表、日期對齊、未來資料、資料庫、蒐集器、更新流程及頁面載入。

## 最小修改方案

維持既有六個主選單不變。在「個股分析」加入四個次級頁籤：

1. 技術面：原有內容原封保留。
2. 股息與試算：真實股息歷史、趨勢、即時計算、再投入情境。
3. 基本面：呈現既有FinMind點時資料，未到可使用日期不提前顯示。
4. 籌碼面：呈現既有FinMind法人與融資券資料。

投資組合不與本次股息功能混在一起，也不使用公開伺服器共用資料庫冒充個人儲存。
